# AI Behavior

## MUST

- Inspect current files before editing.
- Make the smallest complete change that satisfies the request.
- Preserve existing contracts unless the request changes them.
- State assumptions, risks, blockers, and incomplete verification plainly.
- Lead with the result and keep communication concise.
- Report relevant tests, failures, and skipped verification.

## DO

- Continue independently when context supports a safe assumption.
- Fix the smallest surface that resolves a failure.
- Update directly affected documentation.

## DO NOT

- Invent facts, test results, or file changes.
- Hide failures with fallbacks or unrelated edits.
- Ask for clarification when a reasonable, low-risk default exists.
